## Goal

Make a practical, safe release candidate: preserve the working Direct onboarding flow; support owner-key access from more than one phone; make the currently shipped ServerSmartPlug path deterministic enough for normal use; and release only after the defined core source/build/device gates are evidenced. Exhaustive endurance, destructive-storage, and AC/load certification-style work remains explicitly deferred rather than blocking this practical release path.

6. Each completed item must cite concrete source/build/test/device evidence in its next tracker update.
