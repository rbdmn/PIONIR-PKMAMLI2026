# Internal development records

`SmartPlug-internal-records.rar` preserves historical engineering material
removed from the browsable repository: progress trackers, validation notes,
evidence snapshots, diagnostics, generated reports, legacy source copies, and
historical firmware/server artifacts.

The archive is retained for traceability only. It is not an input to Android,
SmartPlug, or ServerSmartPlug builds. The active source code and public build
documentation remain in the repository root, `SmartPlug/`, and
`ServerSmartPlug/`.
